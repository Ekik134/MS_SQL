## Что изучалось
На занятии были рассмотрены практические аспекты работы с хранимыми процедурами и группировкой данных в MS SQL Server: создание и вызов процедур, передача параметров, выполнение операций вставки и передачи данных между таблицами, а также различные способы группировки — классический `GROUP BY`, операторы `CROSS APPLY` и `OUTER APPLY`, и оконные функции (`OVER`).

## Суть задания
Выполнить практические задания по двум направлениям:

### Процедуры
1. **Задача 1** — создать хранимую процедуру для вычисления среднего балла (например, по студентам или группам).
2. **Задача 3** — создать процедуру добавления нового студента: процедура принимает параметры и вставляет запись в таблицу; показать результат выполнения.
3. **Задача 4** — создать процедуру перевода (transfer) — например, перевод студента из одной группы в другую или перевод средств; продемонстрировать результат.

### Группировки
1. **Классические группировки** — использовать `GROUP BY` с агрегатными функциями (`COUNT`, `SUM`, `AVG`) для получения сводных данных.
2. **CROSS APPLY** — продемонстрировать работу оператора `CROSS APPLY`, который выполняет табличную функцию или подзапрос для каждой строки внешнего запроса, возвращая только совпадающие строки.
3. **OUTER APPLY** — продемонстрировать работу оператора `OUTER APPLY`, аналогичного `CROSS APPLY`, но возвращающего все строки внешнего запроса, даже если для них нет совпадений (аналог `LEFT JOIN` для табличных функций).
4. **Оконные функции** — использовать оконные функции с `OVER()` для вычисления агрегатов и ранжирования без сворачивания строк: `ROW_NUMBER()`, `RANK()`, `SUM() OVER()`, `AVG() OVER()` и другие.
