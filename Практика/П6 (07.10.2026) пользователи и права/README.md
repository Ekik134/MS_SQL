## Что изучалось
На занятии были рассмотрены основы администрирования безопасности в MS SQL Server: создание учётных записей уровня сервера (SQL Server и Windows NT), создание схем и пользователей базы данных, назначение серверных ролей и ролей БД, а также выдача и отзыв прав доступа (GRANT/DENY/REVOKE) как через графический интерфейс, так и через T-SQL и хранимые процедуры.

## Суть задания
Выполнить практические задания по управлению пользователями, ролями и правами доступа в MS SQL Server:

1. **Создание учётной записи MS SQL Server** — создать логин средствами SSMS (графический интерфейс).

2. **Создание учётной записи Windows NT** — попытаться создать логин на основе учётной записи Windows; при отсутствии прав появляется соответствующее предупреждение.

3. **Создание учётной записи через хранимую процедуру** — использовать системные процедуры (например, `sp_addlogin`) для создания логина.

4. **Создание схемы** — создать схему в базе данных через SSMS.

5. **Создание пользователя БД** — создать пользователя базы данных, привязанного к логину, через графический интерфейс.

6. **Создание пользователя БД через хранимые процедуры:**
   - `sp_adduser` — позволяет задать роль пользователя через параметр `group_name`;
   - `sp_grantdbaccess` — создаёт пользователя с ролью `public` по умолчанию;
   - `sp_changedbowner 'login'` — меняет владельца базы данных.

7. **Назначение ролей сервера** — добавить и исключить серверные роли (например, `sysadmin`, `securityadmin`) через хранимые процедуры и через T-SQL (`ALTER SERVER ROLE ... ADD MEMBER`).

8. **Назначение ролей БД** — добавить и исключить роли базы данных (например, `db_datareader`, `db_datawriter`) через хранимые процедуры (`sp_addrolemember`/`sp_droprolemember`) и через T-SQL (`ALTER ROLE ... ADD MEMBER`).

9. **Права доступа** — выдать и отобрать права:
   - на работу внутри таблицы (`GRANT SELECT/INSERT/UPDATE ON ... TO ...`, `DENY`, `REVOKE`);
   - на работу по серверу (серверные разрешения).
