## Что изучалось
На занятии были рассмотрены практические приёмы работы с T-SQL в MS SQL Server Management Studio: манипулирование данными (изменение строк, добавление столбцов), агрегация и группировка данных, вычисление статистических показателей (сумма, среднее, процент), использование блоков `BEGIN...END` с переменными, условных конструкций `IF...ELSE` и выражения `CASE` для ветвления логики в запросах.

## Суть задания
Выполнить практические задания по работе с таблицами учебной базы данных (TEACHER, SUBJECT, PULPIT, AUDITORIUM_TYPE, AUDITORIUM, FACULTY):

1. **Вывод таблиц** — выбрать данные из нескольких таблиц базы для ознакомления со структурой.

2. **Изменение таблицы** — продемонстрировать исходную таблицу, выполнить команду изменения строки и добавления нового столбца, показать результат.

3. **Группировка данных** — сгруппировать данные по столбцам и вывести результат через `GROUP BY`.

4. **Подсчёт статистики по аудиториям** — привести тип `AUDITORIUM_CAPACITY` к `int` (изначально был `char`), затем вычислить: общее количество мест, количество аудиторий, среднюю вместимость, количество аудиторий с вместимостью выше средней и их процент от общего числа.

5. **Блок BEGIN...END** — объявить переменные через `DECLARE`, вывести их на экран внутри блока `BEGIN...END` с преобразованием типов (`int` → `char`).

6. **BEGIN...END (продолжение)** — вывести только процент аудиторий, вместимость которых превышает среднюю.

7. **IF-ELSE** — проверить наличие строк в таблицах: в `PULPIT` строки есть, в `STUDENT` — нет (таблица не заполнялась), и вывести соответствующее сообщение.

8. **IF-ELSE (продолжение)** — подсчитать количество мест в аудиториях и в зависимости от результата вывести одну из строк.

9. **CASE** — продемонстрировать работу выражения `CASE`: оно идёт сверху вниз и выбирает первый подходящий вариант, после чего прерывает проверку остальных. Показаны два случая: когда первый `WHEN` истинен (выводится он) и когда первый ложен (выводится второй).
