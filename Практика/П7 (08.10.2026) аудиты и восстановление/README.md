## Что изучалось
На занятии были рассмотрены практические аспекты администрирования MS SQL Server в части резервного копирования и восстановления баз данных, а также настройки и проверки серверного аудита с записью событий в файловую систему.

## Суть задания
Выполнить практические задания по двум направлениям:

### Аудиты
1. **Создание и активация серверного аудита** — настроить аудит с записью в файл в указанную директорию.
2. **Проверка результатов аудита** — убедиться, что события фиксируются и доступны для чтения через `sys.fn_get_audit_file`.
3. **Просмотр папки с логами** — проверить, что файлы аудита физически создаются в заданной директории (`C:\AuditLogs\`).

### Восстановление
1. **Подготовка к восстановлению** — выбрать базу данных, проверить наличие резервных копий, определить точку восстановления.
2. **Настройка параметров восстановления** — указать режим восстановления (например, `RECOVERY` или `NORECOVERY`), выбрать файл резервной копии, при необходимости — опции `REPLACE` и `WITH MOVE` для переноса файлов данных и логов.
3. **Выполнение восстановления** — запустить процесс и проверить успешность операции.
