# Дисциплина "Теория баз данных. Программирование MS SQL Server"
Репозиторий предназначен для хранения всех материалов, связанных с дисциплиной, включа ДЗ, практику и теоритические материалы.

## Описание дисциплины
Изучение данной дисциплины направлено на освоение навыков работы с реляционными базами данных при помощи языка TSQL в среде MS SQL Server.

## Навигация по работам

| Папка | Содержимое |
| :--- | :--- |
| **ДЗ** | Домашние задания по дисциплине. Состоит из самого выполненного задания (задание.md), фотоматериалов к заданию (папка SCRINSHOTS) и README файла, кратко объясняющего суть задания и изучаемой темы. |
| **Конспекты** | Теоретические материалы лекций. |
| **Практика** | Практические работы по основным темам курса, выполняемые на занятиях. Состоит из самого выполненного задания (практика.md), фотоматериалов к заданию (папка SCRINSHOTS) и README файла, кратко объясняющего суть задания и изучаемой темы. |
| **Самостоятельные** | Задания для контроля усвоенных знаний. |
