## Что изучалось
На занятии были рассмотрены практические аспекты работы с представлениями (VIEW) в MS SQL Server: создание представлений на основе таблиц, просмотр данных через представление, изменение определения представления через `ALTER VIEW`, а также проверка модифицируемости представлений — способности изменять данные в исходной таблице через операции над представлением.

## Суть задания
Выполнить практические задания по работе с представлениями в T-SQL:

1. **Представление 1** — создать представление, просмотреть его, изменить через `ALTER VIEW`, снова просмотреть. Доказать модифицируемость: изменить данные через представление и убедиться, что соответствующие данные изменились в оригинальной таблице `STUDENT` (сравнить состояние до и после). Вывод: в MS SQL Server практически любое представление является модифицируемым, если оно не содержит агрегатов, `DISTINCT`, `GROUP BY` и т.п.; ограничить редактирование можно только через права доступа.

2. **Представление 2** — создать представление, попытаться ограничить права на редактирование. Поскольку текущая учётная запись обладает правами администратора, запрет не срабатывает — администратор всё равно может редактировать данные. Предполагается, что для обычного пользователя представление было бы немодифицируемым.

3. **Представление 3** — создать и просмотреть ещё одно представление (без дополнительных манипуляций с правами).
