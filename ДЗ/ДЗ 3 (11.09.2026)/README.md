## Что изучалось
На занятии были рассмотрены практические аспекты создания и использования функций и хранимых процедур в MS SQL Server: создание скалярной функции с возвратом значения (`CREATE FUNCTION`), использование математических и строковых функций внутри тела функции, а также создание хранимой процедуры с объявлением переменных, вычислениями и вызовом через `EXEC`.

## Суть задания
Выполнить практические задания по двум направлениям:

### Функции
1. **Создание скалярной функции** `ExampleFunc` — функция возвращает строку `VARCHAR(MAX)`, в которой собраны результаты работы различных встроенных функций:
   - **Математические функции**: `ROUND` (округление), `FLOOR` (нижнее целое), `CEILING` (верхнее целое), `POWER` (возведение в степень), `SQRT` (квадратный корень), `ABS` (абсолютное значение), `PI` (число π).
   - **Строковые функции**: `SUBSTRING` (подстрока), `LTRIM` (удаление пробелов слева), `RTRIM` (удаление пробелов справа), `LOWER` (нижний регистр), `UPPER` (верхний регистр), `REPLACE` (замена), `SPACE` (строка пробелов), `REPLICATE` (повтор строки).
2. **Вызов функции** — выполнить `SELECT dbo.ExampleFunc()` и получить строку с результатами всех операций, наглядно демонстрирующую работу каждой функции.

### Процедуры
1. **Создание процедуры** `DiffBetweenEnrolledAndGraduated` — процедура объявляет две переменные (`@a`, `@b`), вычисляет:
   - `@a` — общее количество студентов (`COUNT(*)` из `STUDENT`);
   - `@b` — количество выпустившихся студентов (`COUNT(*)` из `STUDENT`, где `GRADUATION_YEAR IS NOT NULL`);
   - выводит разницу `@a - @b` как «разница_между_поступившими_и_выпустившимися».
2. **Вызов процедуры** — выполнить `EXEC DiffBetweenEnrolledAndGraduated` и получить результат — количество студентов, которые ещё не выпустились (в примере — 11).
