## Что изучалось
На занятии были рассмотрены основы работы с транзакциями в MS SQL Server: управление транзакциями (BEGIN/COMMIT/ROLLBACK), обработка ошибок через TRY...CATCH, поведение режима XACT_ABORT, использование точек сохранения (SAVE TRANSACTION), а также уровни изоляции и связанные с ними аномалии чтения.

## Суть задания
Выполнить четыре практических задания по транзакциям в T-SQL:

1. **Основы транзакций** — создать таблицу Accounts с тремя счетами, реализовать перевод 1000 руб. между счетами через BEGIN/COMMIT, а затем смоделировать ошибочную транзакцию и откатить её через ROLLBACK.

2. **Обработка ошибок** — реализовать перевод внутри конструкции BEGIN TRY...END TRY / BEGIN CATCH...END CATCH, в блоке CATCH выполнить ROLLBACK при @@TRANCOUNT > 0 и вывести ERROR_MESSAGE() и ERROR_NUMBER(). Сравнить поведение при XACT_ABORT ON и OFF.

3. **Вложенные транзакции и SAVE TRANSACTION** — смоделировать три операции в одной транзакции (списание, зачисление, запись в лог), поставить SAVE TRANSACTION SavePoint1 после первой операции, при ошибке на третьей откатиться только к точке сохранения и завершить транзакцию через COMMIT. Объяснить, почему ROLLBACK TRANSACTION SavePoint1 не уменьшает @@TRANCOUNT.

4. **Уровни изоляции** — на примере двух параллельных сессий (одна обновляет строку без коммита, вторая читает) сравнить поведение уровней READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ и SNAPSHOT, заполнить таблицу «уровень → поведение» и сделать вывод о выборе уровня для системы складского учёта.
