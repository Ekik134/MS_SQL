# КОНСПЕКТ

## 1. Основные понятия безопасности

| Термин | Определение |
| :--- | :--- |
| **Аутентификация** | Процесс проверки подлинности учетных данных пользователя, чтобы не допустить использования системы несанкционированными пользователями. |
| **Авторизация** | Процесс, применяемый к пользователям, уже получившим доступ к системе, чтобы определить их права на использование определенных ресурсов. |

## 2. Иерархия компонентов

**Компьютер → Сервер (экземпляр) → БД (часть экземпляра) → Таблицы → Данные**

## 3. Типы данных БД

| № | Категория | Примеры |
| :--- | :--- | :--- |
| 1 | Битовые | — |
| 2 | Целочисленные | `int` |
| 3 | Дробные | `real`, `float`, `decimal` |
| 4 | Символьные | `char`, `varchar` (ASCII), `nvarchar` (Unicode) |
| 5 | Дата и время | `datetime`, `smalldatetime` |
| 6 | Специальные | `text`, `bit` (boolean), `image` |
| 7 | Денежные | `money` |

## 4. Физическое хранение данных

### 4.1. Файлы БД

| Тип файла | Расширение | Назначение |
| :--- | :--- | :--- |
| Первичный | `.mdf` | Основной файл данных |
| Вторичные | `.ndf` | Дополнительные файлы данных |
| Журнал транзакций | `.log` | Запись транзакций |

### 4.2. Файловые группы

| Тип группы | Состав |
| :--- | :--- |
| Вторичная файловая группа | Только вторичные файлы |
| Первичная файловая группа | Первичные + вторичные файлы |

### 4.3. Единицы хранения

| Единица | Размер | Описание |
| :--- | :--- | :--- |
| **Страница** | 8 Кб | Основная единица хранилища данных. Состоит из заголовка (96 байт), строк (содержимое) и таблицы смещений строк. |
| **Экстент** | 64 Кб | Физическая единица дискового пространства для выделения памяти под таблицы и индексы. Включает 8 последовательных страниц. |

## 6. Системные БД

| БД | Назначение |
| :--- | :--- |
| `master` | Главная БД сервера. Хранит информацию о пользователях, настройки, информацию о БД и др. |
| `model` | Шаблон для создания БД |
| `msdb` | Информация о выполняемой работе (команды, бэкапы) |
| `tempdb` | Хранилище временных объектов |
| `resource` | Системные объекты SQL Server |

## 7. Установка и начало работы

**Необходимое ПО:** SQL Server 2025 + MS SQL Server Management Studio.

**Порядок действий:**
1. Скачать сервер (инструкция: https://blog.argogeo.ru/арго-6/самостоятельная-установка-sql-server-2025-express/).
2. Создать сервер в SQL Server → подключиться к нему в MS SQL Server Management Studio.
3. Создать БД внутри экземпляра сервера (требуются права администратора).
4. Создать таблицу.
5. Создать ряды (через боль).

### Пример создания таблицы

```sql
USE [college]
GO
CREATE TABLE [dbo].[Users] (
    [Id] INT IDENTITY(1,1) PRIMARY KEY,
    [Login] NVARCHAR(50) NOT NULL UNIQUE,
    [Age] INT NOT NULL
);
GO
```

## 9. Основы T-SQL

### 9.1. Пакет

**Пакет** - это группа операторов T-SQL, которая обрабатывается сервером СУБД вместе​.

### 9.2. Основные операторы

| Оператор | Назначение |
| :--- | :--- |
| **DECLARE** | Инициализировать переменную |
| **​SET, SELECT** | Присвоить значение |
| **PRINT** | Вывести в виде строки |
| **CAST** | Преобразовать тип данных |

### 9.4. Встроенные функции
1. Арифметические операции и встроенные функции (ROUND, FLOOR, POWER, LOG и т.д.)
2. Конкатенация строк и строковые функции
3. Функции даты и времени

### 9.5. Управляющие конструкции

| Конструкция | Назначение |
| :--- | :--- |
| `BEGIN-END` | Ограничители единого логического пакета |
| `IF-ELSE`, `CASE (WHEN)` | Условные операторы |
| `WHILE` | Цикл |
| `TRY/CATCH` | Обработка ошибок |
| `RAISERROR` | Вызов ошибки |
| `WAITFOR` | `DELAY`: на промежуток времени (10 секунд); `TIME`: до определённого времени (до 10:00) |

### 9.6. Курсор

**Курсор** — программная конструкция, которая служит для хранения результата запроса и для обработки строк результирующего набора запись за записью.
